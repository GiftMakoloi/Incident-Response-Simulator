# Deployment Guide: Streamlit Community Cloud

Follow these steps to deploy the Incident Response Simulator live:

1. Push all files (`app.py`, `requirements.txt`, `README.md`, `LICENSE`, `.gitignore`, `scenarios.json`) to a public GitHub repository.
2. Sign in to share.streamlit.io using your GitHub credentials.
3. Click "New app" in the top right corner.
4. Select your repository, set the branch to `main`, and specify `app.py` as the Main file path.
5. Click "Deploy!".
